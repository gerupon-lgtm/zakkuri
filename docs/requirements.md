## 2. はじめに（背景・目的）

- **背景**: 税理士法人の業務では、土地評価の下調べなどで、土地のおおよその形・寸法・面積をつかみたい場面がある。しかし公図には寸法が書かれておらず、正確な形を知るには法務局で地積測量図を取り寄せる必要がある。
- **目的**: 地積測量図を取り寄せなくても、**手元にある情報（公図の画像、公簿面積、分かっている辺の長さ）から、三斜求積付きの参考図面「現況図（概算）」を1枚で作れる**ようにする。
- **期待効果**:
  - 下調べの時間を短くする（【想定】）。
  - 計算の過程を表として残し、ほかの人が検算・確認できるようにする。

## 3. スコープ（対象範囲・対象外）

**対象範囲**
- 公図のスキャン画像・写真の取り込みと、写真の台形補正
- 縮尺の推定（辺の長さ・面積を基準にする。縦横別の縮尺にも対応）
- 三斜法による概算面積の計算と、図面の出力（PDF・印刷）
- 作業ファイル（独自形式）の書き出し・読み込み
- CAD向けの出力（SIMA・DXF）

**対象外・保留**

| 項目 | 理由 | 再検討の条件 |
|---|---|---|
| 登記などの申請に使える図面 | 申請用ではない（発案者回答）。正式な図面の作成は測量士・土地家屋調査士の業務領域 | 申請用途の要望が出ても、原則として対象外のまま |
| 複数の筆をまとめて求積する | 初期版は1筆で成り立つことを優先する | 1筆での流れが安定したら |
| 円弧の正確な計算 | 短い直線の連続による近似で十分（発案者回答） | 近似では誤差が業務上問題になる事例が出たら |
| 公共座標への変換 | 公図の画像からは公共座標が分からない | 基準点の座標を入力したいという要望が出たら |
| SIMA・DXFの読み込み | 端末間の移行は独自形式で行う | CADで修正したものをアプリに戻したい場面が出たら |

## 4. 用語定義

| 用語 | 定義 |
|---|---|
| 公図 | 法務局にある、土地の区画と地番を示した図面。寸法の精度は高くない |
| 公簿面積 | 登記簿に記録された地積（面積） |
| 概算面積 | このアプリが三斜法で計算した面積 |
| 三斜法 | 土地を三角形に分け、各三角形の「底辺×高さ÷2」を合計して面積を出す方法 |
| 倍面積 | 底辺×高さ（三角形の面積の2倍）。三斜求積表で使う |
| 基準 | 縮尺を出すための手がかり。「2点間の実際の長さ」または「面積」 |
| 縮尺 | 画像上の1ピクセルが、実際の何mに当たるか（m/px）。図面には「約1/○○○」の形で表示する |
| 縦横別の縮尺 | 紙の伸び縮みなどで、縦方向と横方向の縮尺が違う場合に、それぞれ別に推定した縮尺 |
| 台形補正 | 斜めから撮った写真を、四隅の指定を使って真上から見た形に直す処理 |
| 地籍調査済み | 国や市町村による地籍調査が終わり、面積が正しいと見なせる土地 |
| 作業ファイル | このアプリの独自形式のファイル。公図の画像と入力内容をまとめて保存する |
| SIMA | 測量データをやりとりするための共通形式。座標と区画を持つ |
| DXF | CADソフト間で図形データをやりとりするための形式 |

### 8.2 機能詳細

#### F-001 画像の読み込み（PDF）

- PDFは、ブラウザの中で画像に変換する（外部へは送らない。C-01）。複数ページのときは、ページを選ぶ。
- 変換の解像度は、頂点を正確に置ける細かさを確保する【想定：300dpi相当】。
- 棄却条件: 方針転換の条件と同じ（核になる機能）。

#### F-016 PWA

- オフラインのときも、PDFの変換ライブラリを含め、全機能が使えるようにする（必要なファイルを端末に保存しておく）。
- 新しい版が公開されたら、画面で更新を案内する。作業中のデータは、更新しても消さない。
- 棄却条件: オフラインで使う場面がなく、ホーム画面からも起動しない状態が続く場合【想定】。

#### F-005 基準の入力

- **辺の長さ**: 画像上の2点を選び、実際の長さを入力する。2点は土地の頂点でなくてもよい（道路の幅などでもよい）【想定】。いくつでも入力できる。
- **公簿面積**: ㎡で入力する。「縮尺の基準に使う」か「比べるだけ」かは、F-006のルールで自動的に決める。
- **地籍調査済み**: チェックを入れる。
- **地目**: 登記の地目一覧（宅地、田、畑、山林、雑種地など）から選ぶ。端数処理（F-008）で使い、図面にも表示する。
- **入力チェック**:
  - 長さ・面積は0より大きい数値とする。
  - 同じ点を2回選んだ基準はエラーにする。
- **棄却条件**: 方針転換の条件と同じ（このアプリの核になる機能）。

#### F-006 縮尺の推定（計算ルール）

| 場面 | 縮尺の決め方 |
|---|---|
| 辺の長さの基準が1本以上あり、地籍調査済みではない | 共通縮尺 s を最小二乗法で求める。s = Σ(lᵢ·Lᵢ) ÷ Σ(lᵢ²)。lᵢは画像上の長さ(px)、Lᵢは実際の長さ(m)。この式は長い辺ほど強く効く。公簿面積は比べるだけに使い、概算面積との差を表示する |
| 地籍調査済みで、公簿面積がある | 共通縮尺は、面積から s = √(公簿面積 ÷ 画像上の面積) で決める。辺の長さは、食い違いの表示だけに使う。図面には「面積基準で縮尺を算出」と書き、差の欄は出さない |
| 辺の長さの基準がなく、面積だけがある | 面積から縮尺を決める（地籍調査済みかどうかは問わない）。図面には「面積基準で縮尺を算出」と書く |
| 基準が0件 | 計算しない。7.1の案内を表示する |

- **基準ごとの食い違い**: 各基準から単独で出した縮尺と、採用した縮尺との差（%）を一覧で表示する。
- **縦横別の縮尺**:
  - 利用者が「縦横別の縮尺を使う」をオンにしたときだけ推定する（既定はオフ）。
  - 縦横の向き: 台形補正をした画像の縦横（紙の縦横）とする。補正しない場合は画像の縦横とする。
  - 推定方法: 各辺について Lᵢ² = (sx·dxᵢ)² + (sy·dyᵢ)² が成り立つものとし、sx²・sy²を未知数とする最小二乗法で求める。dxᵢ・dyᵢは、その辺の画像上の横・縦の長さ。
  - 推定できる条件（次のどちらか）:
    - 向きが30°以上違う辺の長さが2本以上ある
    - 辺の長さが1本以上と、面積がある（sx·sy＝面積の比、という条件を加える）
  - 条件を満たさないときは「縦横別の縮尺は推定できません（材料不足）」と表示し、共通縮尺を使う。
  - 縦横比 sx/sy が1から±3%を超えてずれたときは警告を出す（公図の歪みか、入力ミスかを確かめてもらうため）。
  - 30°・±3%は初期値で、実データを見て調整する（B区分）。
- **地籍調査済みで、縦横別の縮尺をオンにしたとき**: 面積で sx·sy を固定し、辺の長さから縦横比だけを推定する【想定】。
- **棄却条件**: 方針転換の条件と同じ（核になる機能）。

#### F-007 三角形への分割

- 自動分割には耳切り法を使い、凹んだ形にも対応する。候補が複数あるときは、最小の内角がより大きい（細長くない）三角形を優先する。
- 各三角形の底辺は、その三角形で最も長い辺とする。高さは、底辺への垂線の長さとする。
- 手での修正: 隣り合う2つの三角形が共有している対角線を、もう一方の対角線に入れ替えられるようにする【想定】。
- 入力チェック:
  - 頂点が3つ未満のときは分割しない。
  - 外周線が自分自身と交差しているときは、エラーとして修正を促す。
- **棄却条件**: 方針転換の条件と同じ（核になる機能）。

#### F-008 三斜求積の計算（端数処理）

| 項目 | 規則 |
|---|---|
| 底辺・高さ・辺の長さ | m単位で、小数第3位を四捨五入し、第2位（cm）まで表示する |
| 倍面積 | 表に表示した（丸めた後の）底辺×高さで計算し、小数第4位まで表示する。手計算で検算できるようにするため |
| 概算面積 | 倍面積の合計 ÷ 2。不動産登記規則100条に合わせて切り捨てる。宅地・鉱泉地は0.01㎡未満を切り捨て。それ以外の地目（山林・田・畑など）は、10㎡を超えれば1㎡未満を切り捨て（整数で表示）、10㎡以下なら0.01㎡未満を切り捨て |

- **公簿面積との比較**: 差（㎡）と比率（%）を参考として表示する。表記の優先順位は「公簿面積」が主、「概算面積」が参考。
- **棄却条件**: 方針転換の条件と同じ（核になる機能）。

#### F-009 図面情報の入力

  - 入力欄はテキストボックスとカレンダーボタンの併用とする。
  - 8桁の数字を入力すると、入力中に yyyy/MM/dd の形へ整える。
  - 初めてフォーカスしたときは、少し遅らせて全体を選択する。

## 17. 成功基準・受入基準

1. 辺の長さと面積が分かっているテスト用の図形（例: 20m×30mの長方形を斜めから撮った写真）で、概算面積が実際の値の±2%以内に入る。
2. 凹んだ形の土地（L字形など）で、自動分割が成功し、三斜求積表の合計が座標法で出した面積と、丸めの差の範囲で一致する。
3. 縦横別の縮尺が推定できる条件のときは推定でき、条件が足りないときは「推定できません」と表示される。
4. 図面に、注意書き・使った基準・方位記号・公簿面積・概算面積がそろって載る（C-03）。
5. ブラウザの開発者ツールで、画像や入力内容が外部へ送られていないことを確かめる（C-01）。
6. スマホで書き出した作業ファイルを、PCで読み込んで同じ状態から再開できる。
6-2. PDFの公図（複数ページを含む）を読み込み、ページを選んで作業できる。
6-3. 一度読み込んだ後、通信を切った状態でも、PDFの読み込みから図面の出力まで全部できる。
7. 作成日の入力欄が、8桁入力の整形・カレンダーとの相互反映・不正な日付の検出を満たす。対象のスマホの実機で確認する。
8. 画面のフッタに版とコピーライトが表示され、版がリリース情報と一致する。
